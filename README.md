# veraldar

**Veraldar is the organization.** It holds products — hardware or software.
It is not itself a product.

## Products

**yggdrasil** — the world-tree, one installable product:

| part | what it is |
|---|---|
| root | the brain — installable on any computer |
| trunk | the private line between roots and the end user — tailscale today → webrtc → wireguard |
| branch | the end-user app — the current branch is named **bifrost** |

Repos: [yggdrasil](https://github.com/veraldar/yggdrasil) (the root + the tree) ·
[bifrost](https://github.com/veraldar/bifrost) (the branch app).
