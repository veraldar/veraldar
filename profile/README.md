# 🌳 Veraldar

**The world-tree runtime** — local-first, self-hosted agent infrastructure.

Nine packages, one tree:

| Package | What it is |
|---|---|
| [`yggdrasil-core`](https://github.com/veraldar/yggdrasil-core) | Shared foundation: PG connections, graph dataclasses, CLI conventions |
| [`yggdrasil-seidr`](https://github.com/veraldar/yggdrasil-seidr) | Agent-to-agent communication, dispatch, sessions, doctrine |
| [`yggdrasil-skid`](https://github.com/veraldar/yggdrasil-skid) | Per-agent task queue & scheduler |
| [`yggdrasil-flow`](https://github.com/veraldar/yggdrasil-flow) | Multi-step workflow engine (DAGs, letters, retries) |
| [`yggdrasil-project`](https://github.com/veraldar/yggdrasil-project) | Projects → phases → tickets → agents |
| [`yggdrasil-letter`](https://github.com/veraldar/yggdrasil-letter) | Async agent-to-agent mail |
| [`yggdrasil-context`](https://github.com/veraldar/yggdrasil-context) | Semantic memory, graph index, context restore |
| [`yggdrasil-viz`](https://github.com/veraldar/yggdrasil-viz) | Fleet dashboards (Next.js) |
| [`yggdrasil-ygg`](https://github.com/veraldar/yggdrasil-ygg) | Encrypted export / restore / deploy tooling |

*Roots in Norse myth: Veraldar tré, the world-tree holding the nine realms.*

Status: private bootstrap — public rollout in progress. contact@veraldar.org
